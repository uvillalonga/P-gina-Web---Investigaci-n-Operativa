Guía de Armado en Excel

Fórmulas y lógica celda por celda para resolver parciales de Simulación.

Estructura General
Columnas del Modelo de Simulación
La tabla de parcial tiene una columna por cada variable del sistema. Entendé la lógica de cada una antes de armar las fórmulas.
# Columna Variable Tipo Descripción
A N° Azar RND Aleatorio Número random uniforme [0,1)
B Tiempo entre Arribos Δt Fórmula Inversa exponencial aplicada al RND
C Reloj Llegada al Sistema t_arr Acumulado Cuándo llega el cliente al sistema
D Llegada al Servidor t_ini MAX Cuándo empieza a ser atendido
E Estado del Servidor — Condicional Libre / Ocupado en el momento de llegada
F Tiempo de Espera (Wq) Wq Resta D − C: cuánto esperó en la fila
G Tiempo de Servicio 1/μ Fórmula / Fijo Duración de la atención
H Reloj Salida del Sistema t_sal D + G D + G: cuándo sale del servidor
I Tiempo Total en Sistema (W) W Resta H − C: tiempo total desde que llegó
Paso a Paso
Fórmulas Celda por Celda
Cada sección explica la lógica y la fórmula exacta a escribir en Excel. Las celdas de ejemplo asumen que la fila 2 es la primera orden.
1
Generación de Azar y Tiempos
Col A y B

La columna N° Azar (A) genera un número aleatorio uniforme entre 0 y 1. La columna Tiempo entre Arribos (B) aplica la inversa de la exponencial negativa para convertir ese azar en un tiempo real. 

' Columna A — Número Azar
=ALEATORIO()

' Columna B — Tiempo entre Arribos (Exponencial)
' media = tiempo medio entre llegadas (p.ej. 5 min)
=REDONDEAR.MAS(-media * LN(1 - A2); 0)
💡 ¿Por qué LN(1 - RND)? Es la inversa de la CDF exponencial: F⁻¹(u) = −(1/λ)·ln(1−u). Como 1−RND también es uniforme, se puede simplificar a −media·LN(RND) y el resultado es el mismo.
2
Reloj de Llegada al Sistema
Col C

Esta columna acumula los tiempos entre arribos para obtener el instante exacto en que cada cliente entra al sistema (no al servidor, sino a la fila). La primera orden siempre llega al tiempo igual a su propio delta. 

' Fila 2 (primera orden)
=B2

' Fila 3 en adelante
=C2 + B3
' → generalizable: =C_anterior + B_actual
📌 Esta columna es el Reloj del Sistema. Solo registra cuándo llega el cliente, independientemente de si el servidor está libre u ocupado.
3
Llegada al Servidor — El Choque
Col D — Celda Crítica

Esta es la celda más importante del modelo. Responde a: ¿cuándo empieza a ser atendido el cliente? Hay dos posibilidades: si el servidor está libre, empieza inmediatamente al llegar. Si está ocupado, espera hasta que el anterior termine. El MAX resuelve ambos casos de forma elegante. 

' Fila 2 (primera orden — no hay Salida_Anterior)
=C2

' Fila 3 en adelante
=MAX(C3 ; H2)
' → MAX(Llegada_al_Sistema_Actual ; Reloj_Salida_Anterior)

' Lectura en español:
' "Empiezo a ser atendido cuando LLEGUE O cuando el servidor quede libre,
'  lo que ocurra MÁS TARDE"
⚡ Si C3 ≥ H2 → el servidor estaba libre, no hay espera, D = C.
Si C3 < H2 → el servidor estaba ocupado, hay espera, D = H2 (hereda el fin del anterior).
4
Estado del Servidor y Colas (Lq, L)
Col E

Con un condicional SI determinamos si el cliente encontró el servidor libre u ocupado al llegar. Esto permite calcular el porcentaje de clientes que esperaron y estimar Lq. 

' Columna E — Estado del Servidor
=SI(C2 >= H1; "Libre"; "Ocupado")

' C2 = Llegada al Sistema del cliente actual
' H1 = Salida del cliente anterior

' Para contar L_q (clientes en fila):
=CONTAR.SI(E:E; "Ocupado")
📊 El estado "Ocupado" equivale a que el cliente tuvo que esperar en cola (Wq > 0). La fracción de "Ocupado" sobre el total aproxima P(espera) = ρ.
5
Cálculo de Tiempos (Wq y W)
Col F e I

Wq (espera en cola) es simplemente la diferencia entre cuándo empezó a ser atendido y cuándo llegó. Si no esperó, da 0. W (tiempo total en el sistema) es la diferencia entre cuándo salió y cuándo llegó. 

' Columna F — Wq: Espera en Cola
=D2 - C2
' D = Llegada al Servidor, C = Llegada al Sistema
' Siempre ≥ 0 (si servidor libre → D=C → Wq=0)

' Columna I — W: Tiempo Total en el Sistema
=H2 - C2
' H = Reloj Salida, C = Llegada al Sistema

' Métricas finales (en celdas aparte)
Wq promedio = =PROMEDIO(F2:F_n)
W promedio  = =PROMEDIO(I2:I_n)
🎯 La relación W = Wq + (1/μ) siempre debe cumplirse en promedio. Si no cierra, revisá la columna D (Llegada al Servidor).
