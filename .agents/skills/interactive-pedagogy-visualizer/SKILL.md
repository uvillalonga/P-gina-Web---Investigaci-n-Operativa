# Interactive Pedagogy & Visualizer Guidelines

This skill guides the design of engaging, concise, and dynamic educational components that replace dense blocks of static text with active learning widgets.

## Principles of Engaging Educational UI

1. **Active Discovery > Passive Reading:**
   - Don't present long static paragraphs. Instead, allow the user to click, drag, hover, or flip cards to reveal concepts.
2. **Visual Metaphors & Micro-Animations:**
   - Use dynamic balances (scales) to illustrate trade-offs.
   - Use color-coded state transitions (green for optimal, red for loss, yellow for warning).
   - Use CSS pulse, hover elevation (`transform: translateY(-4px)`), and glassmorphic glow.
3. **Chunking & Flashcard Patterns:**
   - Split complex explanations into step-by-step progress cards, interactive tabs, or flip flashcards.
   - Use badges and icons for immediate cognitive recognition.
4. **Interactive Trade-off Simulators:**
   - Provide interactive sliders or buttons where changing a parameter immediately triggers a visual animation and updates math formulas live.
